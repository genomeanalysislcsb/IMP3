# About

The Integrated Meta-Omics Pipeline (IMP, [paper](https://doi.org/10.1186/s13059-016-1116-8)) is a reproducible and modular pipeline for large-scale integrated analysis of coupled metagenomic (MG) and metatranscriptomic (MT) data.

IMP3, an updated and extended version of the original IMP workflow, incorporates read preprocessing, assembly (including optional iterative co-assembly of MT and MG data), taxonomic and functional analysis of microbial community structure, binning, as well as summary and visualization.

The documentation of IMP3 can be found [here](https://imp3.readthedocs.io/en/latest/index.html).

If you have any trouble using the pipeline, have questions or a feature request, please consider to open an [issue](https://git-r3lab.uni.lu/IMP/imp3/-/issues).
In case you want to contribute to the project, visit the [wiki](https://git-r3lab.uni.lu/IMP/imp3/-/wikis/home) to see the code formatting convention.
