# Uni.lu Users

* If you're using IMP on the unilu hpc, you probably already have it installed in your group's project folder. If you want to install imp anyways, checkout either the {doc}`../installation/quickstart` or {doc}`../installation/installation`. 
* Make sure to not repeatedly download the databases needed for the Assembly as they are easily over 1TB big and would unnecessarily take up space on the cluster.
* If your team has ever used IMP, there should be a shared snakemake environment and database folder to save space and resources.
* You can of course have multiple installations of IMP with different settings.
