# IMP3 steps: Taxonomy

Additionally, [kraken2](https://ccb.jhu.edu/software/kraken2/) is run on the contigs from the {ref}`Assembly <step_assembly>` step. Kraken 2 is a taxonomic classification system that assigns taxonomic labels to DNA sequences and works by comparing sequences from a sample to a database of known genomic sequences, efficiently identifying the microorganisms present.

Kraken 2 enhances the IMP pipeline by rapidly assigning taxonomic labels to metagenomic sequences, enabling precise identification of microbial composition.
